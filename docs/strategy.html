Mathematical Decomposition of the Performance Metric

The official competition score is the Distance-Weighted Tversky Index (DW-Tversky) with parameters $\alpha = 0.2$, $\beta = 0.8$, and support radius $R = 300\text{ m}$ (3 pixels):

k(d) = max(1 - d / 3, 0)
TP_w = ∑_{g ∈ G} max_{x : d(x,g) ≤ 3} [ p(x) · k(d(x,g)) ]
FP_w = ∑_{x : p(x) > 0} p(x) · [ 1 - max_{g ∈ G} k(d(x,g)) ]
FN_w = ∑_{g ∈ G} [ 1 - max_{x : d(x,g) ≤ 3} [ p(x) · k(d(x,g)) ] ]
DTI = TP_w / [ TP_w + 0.2·FP_w + 0.8·FN_w + ε ]

Why False Negatives are 4x More Punitive

Since $FN_w = |G| - TP_w$, we substitute into the denominator:

Denominator = TP_w + 0.2·FP_w + 0.8·(|G| - TP_w) = 0.2·(TP_w + FP_w) + 0.8·|G|

Notice that capturing an additional true positive pixel simultaneously reduces $FN_w$ and increases $TP_w$. The net gain on the numerator is $+1.0 \Delta TP_w$, whereas the denominator only grows by $+0.2 \Delta TP_w$. Therefore, high recall is heavily rewarded. Overly conservative models (like Pindrop in GEMSDOE3) fail because missing true faults is penalized four times more heavily than generating a false positive.
