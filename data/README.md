# data/ — competition file placement

Run `bash scripts/download_competition_data.sh` for the fetch list, place files
here, then run `python scripts/prepare_data.py`.

| File | Source | Required |
| --- | --- | --- |
| `training_features.tif` | DrivenData data tab (login) | yes |
| `sample_submission.tif` | DrivenData data tab (login) — **format template** | yes |
| `training_labels.*` | DrivenData data tab (login), raster and/or vector | yes (either form) |
| `1m_DEM_links.csv` | DrivenData data tab (login) | for H3 calibration |
| `SHA256SUMS.txt` | your `sha256sum` record | recommended |
| `manifest.json` | generated by `prepare_data.py` | generated |

Large binaries are git-ignored; only this README and `manifest.json` are
committed (the manifest carries hashes + grid facts for audit).
