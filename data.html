Audit Flags & Field Irregularities

1. GDR Submission 1391: The link https://gdr.openei.org/submissions/1391 currently resolves to an HTTP 404/empty response on OpenEI. The survey data is directly preserved via the USGS GeoDAWN ScienceBase catalog.

2. Sample Submission Binary Layout: DrivenData's distributed sample_submission.tif has 60,988 positive pixels rather than an all-zero raster. It serves as an exact reference geometry for the footprint and nodata mask.

3. Feature Holes Inside Footprint (verified decomposition 2026-09-26): Feature nodata is the finite float −3.4×10³⁸, not NaN. Inside the 5,167,373-px label footprint, 3,061 px lack data on bands 1–5 and 7–19, plus 12 extra on band 6 (tc) — union 3,073 px. Separately, 1,540 finite feature px lie outside the label footprint (band-1 whole-grid valid = 5,165,852). Model code must map nodata→NaN (read_band_as_nan) and never treat −3.4×10³⁸ as a measurement.

4. Missing magnetic-source-depth band: the problem text lists a "top-of-crustal magnetic source depth estimate" band, but the file's 19 band_name tags contain none (verified; guarded by tests/test_bandlayout.py). H5 was redefined accordingly.
